## 0. 用語の定義

- **個人情報**: Discord User ID、IP アドレス、その他特定の個人を識別できる情報
- **匿名加工情報**: 個人を特定できない形に加工した情報 (集計統計等)
- **越境移転**: 日本国外のサーバーに個人情報を保存する行為
- **本サービス**: FF14 固定支援 Bot および付随する Web app

## 1. 収集する個人情報の種類

### 1.1 Discord プラットフォームから自動取得

| 項目 | 個人情報該当 | 用途 | 保存期間 |
|---|---|---|---|
| Discord User ID (snowflake) | ✅ 該当 | コマンド実行者の識別、固定メンバー記録 | 削除要請まで or 90日無活動で自動削除 |
| Discord Guild ID | ❌ 非該当 (組織識別子) | サーバー単位のデータ分離 | bot が guild にいる間 |
| Discord Channel ID | ❌ 非該当 | 通知先の特定 | 関連する予定が存在する間 |
| ユーザー名 (display name) | ⚠️ 公開情報 | 識別表示のみ | **保存しない** (都度 API 取得) |
| アバター画像 | ⚠️ 公開情報 | 表示のみ | **保存しない** |

### 1.2 ユーザーがコマンド経由で入力

| 項目 | 個人情報該当 | 用途 | 保存期間 |
|---|---|---|---|
| 予定の日時・メモ・メンション・調整さんURL | △ (内容次第) | アラート機能 | ユーザーが /unschedule で削除するまで |
| 募集テンプレに入力した変数 | △ | テンプレ生成のみ | **保存しない** (リクエスト時のみ処理) |
| 固定メンバー登録 (gameRole, job) | △ (Discord ID 紐付け) | 固定運営支援 | ユーザーが /static-remove で削除するまで |

### 1.3 Web app 利用時 (該当する場合)

| 項目 | 個人情報該当 | 用途 | 保存期間 |
|---|---|---|---|
| Discord OAuth セッション (User ID, username, guilds 一覧) | ✅ 該当 | ログイン状態維持、参加 guild 識別 | セッション期限 (デフォルト 7日) |
| セッション Cookie | ✅ 該当 | 認証セッション維持 | ブラウザを閉じるまで |
| アクセスログ (IP, User-Agent, アクセス時刻) | ✅ 該当 | セキュリティ・トラブルシューティング | 30日 |

### 1.4 自動収集しない情報
- 個人を特定する氏名・住所・電話番号・クレジットカード情報 — **一切収集しません**
- ゲーム内アカウント情報 (キャラクター名等) — **ユーザーが自己申告した場合のみ** 保存

## 2. 利用目的

収集した情報は、以下の目的の範囲内でのみ利用します:

1. **本サービスの機能提供** — コマンド応答、アラート通知、テンプレ生成、固定メンバー管理
2. **不正利用の防止** — レート制限超過の検知、規約違反対応
3. **サービス改善** — エラーログから障害分析 (個人特定しない形)
4. **問い合わせ対応** — ユーザーからの連絡への返信

**広告配信・マーケティング・第三者への販売・スコアリング・プロファイリング は行いません。**

## 3. 第三者への提供

以下を除き、第三者にユーザー情報を提供しません:

- **法令に基づく開示請求**への対応 (令状等)
- **サービス運営に必要な業務委託先** (下記 4 参照、APPI 上の「第三者提供」には該当しない取扱い)
- **緊急時の生命・身体・財産の保護** (これらの保護が必要かつ本人同意取得が困難な場合)

## 6. ユーザーの権利 (APPI 準拠)

ユーザーは個人情報保護法に基づき、以下の権利を有します:

### 6.1 開示・訂正・利用停止・削除請求
- **開示請求**: 当サービスが保持する貴方の情報のリストを請求できます
- **訂正請求**: 不正確な情報の訂正を請求できます
- **利用停止請求**: 利用目的範囲外での利用停止を請求できます
- **削除請求**: 利用停止 + データベースからの削除を請求できます

### 6.2 削除方法

**Discord 上** (推奨):
- 個別予定: `/unschedule id:<予定ID>`
- 固定メンバー登録: `/static-remove user:@you` (固定主に依頼) or DM 連絡
- 全データ: `/data delete` コマンド (実装予定)

**メール**:
- 宛先: [連絡先メール]
- 件名: `[Data Delete] <あなたの Discord User ID>`
- 本文: Discord User ID および削除希望範囲

**guild kick**:
- bot を guild から kick した場合、その guild に関連する設定・メンバー情報は **30日後に自動削除** (実装予定、現状は手動対応)

### 6.3 開示方法
メールでの請求から **2週間以内** に、本人確認後、CSV 形式で提供します。手数料は無料。

## 7. Cookie と類似技術 (Web app)

Web app では以下の Cookie を利用します:

| Cookie | 種別 | 用途 | 保存期間 |
|---|---|---|---|
| `__Secure-authjs.session-token` | 必須 | NextAuth セッション維持 | 7日 (アクティブで延長) |
| `__Host-authjs.csrf-token` | 必須 | CSRF 対策 | セッション中 |

**トラッキング目的、広告目的、解析目的の Cookie は使用しません。**

## 8. セキュリティ

### 技術的対策
- DB 接続は TLS で暗号化
- bot トークン・API キー・OAuth secret は Fly.io secrets / Vercel env で暗号化保管
- DB バックアップは自動取得・暗号化保管
- HTTPS 強制 (Web app)
- CSRF / XSS 対策 (Next.js デフォルト + 追加対策)

### 運用的対策
- アクセス可能な運営者は限定的
- 異常検知時は迅速に対応 + 影響ユーザーに通知

### 限界の明示
インターネット上の通信およびデータ保存は 100% 安全ではありません。重大インシデント発生時は、本人および監督官庁 (個人情報保護委員会) に速やかに通知します。
