## 1. 収集する情報

本サービスは、Discord 上で動作する Bot および付随する Web app です。サービス提供のために以下の情報を収集・保存します。

### 1.1 Discord から自動取得する情報
| 項目 | 用途 | 保存期間 |
|---|---|---|
| Discord User ID | コマンド実行者の識別、固定参加者の管理 | 削除リクエストまで |
| Discord Guild ID | サーバー単位のデータ分離 | bot が guild に存在する間 |
| Discord Channel ID | 通知先の特定、Phase チャネルの記録 | 関連する予定が存在する間 |
| ユーザー名・アバター | 識別表示（保存はせず、Discord API から都度取得） | 保存しない |

### 1.2 ユーザーがコマンド経由で入力する情報
| 項目 | 用途 | 保存期間 |
|---|---|---|
| 予定の日時・メモ・メンション | アラート機能 | ユーザーが削除するまで |
| 募集テンプレに入力した変数 | テンプレ生成（生成時のみ） | 保存しない |

### 1.3 Web app 利用時（該当する場合）
| 項目 | 用途 | 保存期間 |
|---|---|---|
| OAuth セッション情報 (Discord OAuth 経由) | ログイン状態維持 | セッション期限まで |
| Cookie | 認証セッション維持 | セッション期限まで |

## 2. 情報の利用目的

収集した情報は、以下の目的にのみ利用します。

- 本サービスの機能提供 (コマンド応答、アラート通知、テンプレ生成等)
- サービス改善のためのエラーログ収集 (個人を特定しない形式)
- ユーザーからの問い合わせ対応

**広告配信、マーケティング、第三者への販売は行いません。**

## 3. 第三者提供

## 6. Cookie と類似技術 (Web app 利用時)

Web app では認証セッション維持のために以下の Cookie を利用します:

- **セッション Cookie** (必須): ログイン状態維持。ブラウザを閉じると削除
- **CSRF トークン** (必須): セキュリティ対策

トラッキング目的・広告目的の Cookie は使用しません。

## 7. セキュリティ

- データベースへの接続は TLS で暗号化されています
- bot トークン・API キーは secret 管理 (Fly.io secrets / Vercel env) で保護
- バックアップは自動取得され、暗号化された状態で保管されます

しかし、インターネット上の通信は100%安全ではありません。重大なセキュリティインシデント発生時は、影響を受けるユーザーに速やかに通知します。
