# 削除要請窓口 / Takedown Policy

本サービスは、第三者から **著作権・知的財産権・プライバシー** に関する削除要請を受けた場合、**24時間以内** (営業日基準) に対応する方針です。

最終更新: 2026-05-25

---

## 1. 削除対象になりうるコンテンツ

### マクロ・処理法・解説 (data/contents/*.yaml)
- 出典元の作者から削除要請がある場合
- 出典元のサイトで非公開化された場合
- 引用範囲が著作権法上の「引用」の範囲を超えていると判断される場合

### 動画・スプレッドシート等の URL
- リンク先が削除/非公開化された場合
- 著作権者から要請があった場合

### 募集テンプレ・サンプルデータ
- テンプレ提供者から要請があった場合

### Square Enix の知的財産関連
- SE から商標・著作権侵害の指摘があった場合
- 「公式」と誤認させる表現の修正・削除要請

### ユーザー個人情報
- 該当ユーザー本人からの削除要請 (詳細は [privacy-policy.md](./privacy-policy.md))
- 第三者が公開を望まないユーザー情報の指摘

## 2. 削除要請の手順

### A. メール (推奨、確実)

宛先: **[運営者メール — 公開前記入]**

件名例:
```
[Takedown] FF14固定支援Bot - <対象コンテンツ>
```

本文に含めてほしい情報:
1. **要請者の氏名 (またはハンドル) と所属/関係性** (作者本人 / 著作権者 / 代理人 等)
2. **対象コンテンツの具体的な特定** (URL、ファイルパス、yaml ID、Phase 番号等)
3. **削除を要請する根拠** (著作権、商標、プライバシー、その他)
4. **連絡先** (返信用メールアドレス)
5. **証明可能なら本人確認資料** (任意、迅速対応のため推奨)

### B. GitHub Issue (公開でよい場合)

https://github.com/mitchkunn/FF14-bot/issues/new

ラベル: `takedown-request`

> ⚠️ Issue は **公開** なので、機密情報を含めないでください。

### C. Discord support server

[招待リンク — 公開前記入]

`#削除要請` チャネル (準備中) でメンション。

## 3. 対応プロセス

```
要請受信
  ↓ (24時間以内)
受信確認・内容精査
  ↓
妥当性確認 (要請者・要請内容)
  ↓
対応決定:
  - 即時削除 → git PR で対応、merge後 deploy
  - 修正対応 → 出典追記・引用範囲縮小等
  - 却下 → 理由を要請者に説明
  ↓ (48時間以内)
要請者に対応結果を通知
```

## 4. 透明性レポート

公開Bot 化後 (Phase B+) は、年に1回:
- 受信した takedown 要請の件数 (匿名化集計)
- 対応内訳 (即時削除 / 修正 / 却下)
- 主要なケーススタディ (要請者同意を得たもののみ)

を本リポジトリの `docs/legal/transparency/` に公開予定。

## 5. 悪意ある要請への対応

明らかに虚偽・嫌がらせ目的の要請に対しては:
- 内部記録を残す (再発防止)
- 法的措置の検討
- 必要に応じて公開 (本人特定情報を伏せて事例として)
